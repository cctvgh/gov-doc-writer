# 公文写作助手（gov-doc-writer）

面向党政机关、企事业单位文秘场景的中文公文写作助手技能。覆盖 15 种法定文种，严格按 **GB/T 9704-2012《党政机关公文格式》** 生成规范版头、主体与版记，可直接预览打印或转为 Word / PDF。

## 特性

- **15 种法定文种全覆盖**：通知、报告、请示、批复、函、纪要、通报、通告、公告、决定、决议、意见、命令（令）、议案、公报
- **文种自动识别**：从自然语言描述判断文种（"发个通知""打个请示""整理会议纪要"），不明确时主动询问
- **格式严格合规**：A4 版面、页边距 37/35/28/26mm、仿宋_GB2312 三号正文、黑体一级标题、楷体二级标题、每页 22 行 × 每行 28 字、红色分隔版头
- **要素齐备**：发文机关标志、发文字号（六角括号年份）、签发人（上行文）、主送机关、附件说明、署名、成文日期、印章位置、抄送与印发版记
- **语言风格分级**：上行文谦恭、下行文果断、平行文客气，配套公文专用句式（"现将……""妥否，请批示""特此函达"）
- **零编造**：用户未提供要素标注 `[待补充]`，不自行虚构机关、文号、数据

## 快速开始

1. 把本目录放到技能目录下（或直接让智能体加载 `SKILL.md`）。
2. 用自然语言提出需求，例如：

```
帮我写一份通知：关于开展2026年安全生产大检查的通知，主送各下属单位，下周三前报自查结果
```

```
写一个请示，向上级申请机房设备更新经费 50 万元
```

3. 助手会按文种收集必备要素 → 生成 HTML 公文（白底 + 红版头）→ 按需转为 `.docx` / `.pdf`。

## 使用建议

- 发文机关、文号、主送机关等由使用单位按实际填写，本技能只提供规范骨架与语言范式
- 上行文（请示、报告）务必保留签发人栏与"妥否，请批示"类结语
- 报告不得夹带请示事项；请示须一文一事、只写一个主送机关
- 生成后请由本单位文书人员复核用印、密级与分发范围
