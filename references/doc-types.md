## 通知

**适用场景**：发布指示、安排工作、传达精神、告知事项

**格式要点**：
- 标题：发文机关+事由+通知（如"XX县人民政府关于做好XX工作的通知"）
- 主送机关：必须标注
- 正文结构：通知缘由→通知事项→执行要求
- 结语："特此通知"或"请遵照执行"

**示例标题**：关于做好2026年国庆期间安全生产工作的通知

**正文模板**：
```
为做好XX工作，现将有关事项通知如下：
一、XX
二、XX
三、XX
请各单位认真贯彻执行。
```

## 报告

**适用场景**：向上级汇报工作、反映情况、回复询问

**格式要点**：
- 标题：发文机关+事由+报告
- 主送机关：上级机关
- 正文结构：报告缘由→报告内容→结语
- 结语："特此报告""专此报告"
- 注意：报告中不得夹带请示事项

**正文模板**：
```
根据XX要求，现将XX情况报告如下：
一、基本情况
二、主要做法
三、存在问题
四、下一步打算
特此报告。
```

## 请示

**适用场景**：向上级请求指示、批准

**格式要点**：
- 标题：发文机关+事由+请示
- 主送机关：只写一个（不得多头请示）
- 正文结构：请示缘由→请示事项→请求
- 结语："妥否，请批示""当否，请批复"
- 签发人：必须标注（上行文）
- 一文一事

**正文模板**：
```
为XX（目的），拟XX（事项）。
目前XX（现状说明）。
现将有关事项请示如下：
一、XX
二、XX
妥否，请批示。
```

## 批复

**适用场景**：答复下级请示事项

**格式要点**：
- 标题：发文机关+事由+批复
- 主送机关：请示机关
- 正文结构：引述请示→批复意见→执行要求
- 开头："你X《关于XX的请示》（X政〔2026〕X号）收悉。经研究，现批复如下："

**正文模板**：
```
你单位《关于XX的请示》（X〔2026〕X号）收悉。经研究，现批复如下：
一、同意XX。
二、XX。
请抓紧组织实施。
```

## 函

**适用场景**：不相隶属机关之间商洽工作、询问答复、请求批准

**格式要点**：
- 标题：发文机关+事由+函
- 主送机关：对方机关
- 正文结构：函由→事项→请求
- 结语："请予支持""请予函复""特此函达"
- 语气：平等协商，礼貌客气

**正文模板**：
```
为XX（目的），现就XX事宜函告如下：
一、XX
二、XX
请予支持为盼。
```

## 纪要

**适用场景**：记载会议主要情况和议定事项

**格式要点**：
- 标题：会议名称+纪要
- 不设主送机关（普发型）
- 正文结构：会议概况→议定事项
- 格式："时间、地点、主持人、参会人"开头
- 议定事项用"会议认为""会议决定""会议要求"

**正文模板**：
```
XX年X月X日，XX同志主持召开XX会议，研究XX事项。现将会议纪要如下：
会议听取了XX汇报。
会议决定：
一、XX
二、XX
会议要求，各相关部门抓紧落实。
```

## 通报

**适用场景**：表彰先进、批评错误、传达精神

**格式要点**：
- 标题：发文机关+事由+通报
- 主送机关：必须标注
- 正文结构：事实→分析→决定→要求
- 类型：表彰通报/批评通报/情况通报

**表彰通报模板**：
```
近期，在XX工作中，XX单位（同志）表现突出，取得显著成绩。
为表彰先进，经研究，决定给予XX通报表彰。
希望受表彰的单位和个人再接再厉。各单位要以先进为榜样，XX。
```

## 通告

**适用场景**：公布社会各有关方面应遵守或周知的事项

**格式要点**：
- 标题：发文机关+事由+通告（或仅"通告"）
- 可不设主送机关（面向公众）
- 正文结构：通告缘由→通告事项→执行要求
- 结语："特此通告"

**正文模板**：
```
为XX（目的），根据XX（依据），现将XX事项通告如下：
一、XX
二、XX
特此通告。
```

---

## 公告

**适用场景**：向国内外宣布重大事项

**格式要点**：
- 标题：发文机关+事由+公告（或仅"XX公告"）
- 不设主送机关
- 正文：公告事项
- 结语："特此公告"
- 语言：庄重、简明

---

## 决定

**适用场景**：对重大事项作出安排

**格式要点**：
- 标题：发文机关+事由+决定
- 主送机关：视情况标注
- 正文结构：决定缘由→决定内容→执行要求
- 语言：权威、果断

**正文模板**：
```
为XX，经XX研究，决定如下：
一、XX
二、XX
各单位要XX，确保XX落到实处。
```

---

## 决议

**适用场景**：会议讨论通过的重大决策事项

**格式要点**：
- 标题：会议名称+事由+决议
- 不设主送机关
- 正文结构：决议缘由→决议内容
- 开头："XX会议于X年X月X日讨论通过了XX决议"

---

## 意见

**适用场景**：对重要问题提出见解和处理办法

**格式要点**：
- 标题：发文机关+事由+意见
- 主送机关：视情况标注
- 正文结构：意见缘由→具体意见→落实要求
- 结构可分"总体要求""主要任务""保障措施"

---

## 命令(令)

**适用场景**：发布行政法规和规章、宣布重大强制性行政措施

**格式要点**：
- 标题：发文机关+事由+命令（或"XX令"）
- 不设主送机关
- 正文简明
- 署发令机关首长签名

---

## 议案

**适用场景**：各级政府向同级人大提请审议事项

**格式要点**：
- 标题：发文机关+事由+议案
- 主送机关：同级人大
- 正文结构：提请缘由→提请事项
- 结语："请予审议"

---

## 公报

**适用场景**：公布重要决定或重大事项

**格式要点**：
- 标题：会议名称+公报（或"XX公报"）
- 不设主送机关
- 正文：按条目式记述
- 语言：庄重、准确
