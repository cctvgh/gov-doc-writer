# GB/T 9704-2012 公文格式完整规范

## 版面参数

| 项目 | 规范值 |
|------|--------|
| 纸张 | A4（210mm × 297mm） |
| 上边距 | 37mm ± 1mm |
| 下边距 | 35mm ± 1mm |
| 左边距 | 28mm ± 1mm |
| 右边距 | 26mm ± 1mm |
| 每页行数 | 22行 |
| 每行字数 | 28字 |
| 行间距 | 固定值 28-30磅 |

## 字体字号

| 要素 | 字体 | 字号 |
|------|------|------|
| 发文机关标志 | 小标宋体（红色） | 视字数定，一般不大于22mm × 15mm |
| 发文字号 | 仿宋_GB2312 | 三号（16pt） |
| 签发人 | 仿宋_GB2312 | 三号 |
| 标题 | 小标宋体 | 二号（22pt） |
| 主送机关 | 仿宋_GB2312 | 三号 |
| 正文 | 仿宋_GB2312 | 三号 |
| 一级标题（一、） | 黑体 | 三号 |
| 二级标题（（一）） | 楷体_GB2312 | 三号 |
| 三级标题（1.） | 仿宋_GB2312加粗 | 三号 |
| 附件说明 | 仿宋_GB2312 | 三号 |
| 署名、日期 | 仿宋_GB2312 | 三号 |
| 版记 | 仿宋_GB2312 | 四号（14pt） |

## 版头要素

### 发文机关标志
- 由发文机关全称或规范化简称加"文件"组成
- 上行文用发文机关全称加"文件"
- 红色，小标宋体
- 居中排布

### 发文字号
- 编排方式：机关代字+年份+序号
- 格式：X政发〔2026〕12号
- 年份用六角括号〔〕
- 序号不编虚位（1号不编001号）
- 上行文居中，下行文左空一字

### 签发人
- 上行文必须标注
- "签发人："后跟姓名
- 右对齐，与发文字号同行
- 如有会签人，依次排列

### 分隔线
- 红色
- 发文字号下4mm处
- 粗线在上（距版心下边缘约25mm），细线在下
- 粗线约0.35mm，细线约0.15mm

## 主体要素

### 标题
- 发文机关+事由+文种
- 二号小标宋，居中
- 回行时词意完整，排列对称
- 不使用引号、书名号

### 主送机关
- 三号仿宋，左顶格
- 全称或规范化简称
- 多个机关用顿号分隔

### 正文
- 三号仿宋，首行缩进2字
- 结构层次序数：
  - 第一层：一、二、三、（黑体）
  - 第二层：（一）（二）（三）（楷体）
  - 第三层：1. 2. 3.（仿宋加粗）
  - 第四层：（1）（2）（3）（仿宋）

### 附件说明
- 正文下空一行左空二字
- "附件："后跟附件名（全角冒号）
- 多个附件用序号标注

### 发文机关署名
- 正文下右空二字
- 全称或规范化简称
- 联合行文按主办机关在前排列

### 成文日期
- 署名下右空四字
- 阿拉伯数字：2026年9月12日
- 用汉字月日时："九月十二日"（仅特殊公文）

### 印章
- 成文日期上方
- 端正、居中
- 下弧不压成文日期

## 版记要素

### 抄送机关
- 版记第一行
- "抄送："后跟机关名
- 用全角逗号分隔，末尾用句号

### 印发机关和印发日期
- 版记最后一行
- 印发机关左空一字
- 印发日期右空一字
- 用阿拉伯数字

### 分隔线
- 首条分隔线（版记上边缘）：粗线
- 末条分隔线：粗线
- 中间分隔线：细线

## HTML/CSS 换算

将纸面尺寸换算为屏幕显示时：
- 1mm ≈ 3.78px（96 DPI）
- A4 页面：794px × 1123px
- 上边距 37mm ≈ 140px
- 下边距 35mm ≈ 132px
- 左边距 28mm ≈ 106px
- 右边距 26mm ≈ 98px

CSS 模板：
```css
@page { size: A4; margin: 0; }
.doc-page {
  width: 210mm; min-height: 297mm;
  padding: 37mm 26mm 35mm 28mm;
  margin: 0 auto;
  background: #fff;
  font-family: "仿宋", "FangSong", serif;
  font-size: 16pt; /* 三号 */
  line-height: 30pt;
}
.doc-header { text-align: center; color: #C00000; font-family: "STSong","宋体",serif; }
.doc-title { font-family: "STSong","宋体",serif; font-size: 22pt; text-align: center; font-weight: bold; margin: 20px 0; }
.doc-body { text-indent: 2em; }
.doc-h1 { font-family: "黑体","SimHei",sans-serif; font-weight: normal; }
.doc-h2 { font-family: "楷体","KaiTi",serif; }
.doc-separator { border-top: 2px solid #C00000; border-bottom: 1px solid #C00000; height: 4px; margin: 10px 0; }
```
