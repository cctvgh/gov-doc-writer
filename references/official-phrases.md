# 公文常用用语和句式

## 开头用语

| 场景 | 用语 |
|------|------|
| 引述依据 | 根据……精神，按照……要求 |
| 说明目的 | 为做好XX工作，为切实XX |
| 引述来文 | 你X《关于XX的请示》（X〔2026〕X号）收悉 |
| 概述情况 | 现将XX情况报告如下 |
| 提出事项 | 现就XX事项通知如下 |

## 过渡用语

| 场景 | 用语 |
|------|------|
| 总到分 | 现就有关事项XX如下 |
| 分到总 | 综上所述 |
| 转换话题 | 此外、另外、同时 |
| 递进 | 进一步、在此基础上 |

## 结尾用语

| 文种 | 结语 |
|------|------|
| 通知 | 特此通知 / 请遵照执行 / 请认真贯彻落实 |
| 报告 | 特此报告 / 专此报告 |
| 请示 | 妥否，请批示 / 当否，请批复 / 请予审批 |
| 批复 | 此复 / 请抓紧组织实施 |
| 函 | 请予支持 / 请予函复 / 特此函达 / 请查照 |
| 纪要 | 无固定结语 |
| 通报 | 特此通报 |
| 通告 | 特此通告 |
| 公告 | 特此公告 |
| 意见 | 请结合实际贯彻落实 |
| 议案 | 请予审议 |

## 公文常用句式

### 部署工作
- "现就有关事项通知如下"
- "各XX要高度重视，精心组织，确保各项工作落到实处"
- "要XX、XX、XX，切实做好XX工作"

### 汇报情况
- "现将XX情况报告如下"
- "截至目前，已XX"
- "主要做法：一是XX，二是XX，三是XX"

### 请示事项
- "现就XX事项请示如下"
- "拟XX，需XX，妥否，请批示"
- "以上请示，请予批复"

### 答复事项
- "经研究，现批复如下"
- "同意XX"
- "原则同意XX，请XX后实施"

### 商洽事项
- "现就XX事宜致函如下"
- "为做好XX工作，请贵XX予以支持"
- "以上事项，请予函复"

### 表态要求
- "要切实加强XX"
- "要进一步XX"
- "严禁XX"
- "不得XX"

## 常见用语规范

| 错误用法 | 正确用法 |
|---------|---------|
| 研究、决定 | 研究决定（公文不用顿号连接并列动词） |
| 关于贯彻……的通知 | 关于学习贯彻……的通知 |
| 您好 | 公文不使用"您好" |
| 此致敬礼 | 公文不使用"此致敬礼" |
| 2006.9.12 | 2026年9月12日 |
| [2026]12号 | 〔2026〕12号（六角括号） |
| 一、关于XX问题 | 一、XX问题（标题不重复"关于"） |

## 数字使用规则

1. 公文中所有日期、数量均用阿拉伯数字
2. 成文日期格式：2026年9月12日
3. 发文字号年份用六角括号〔〕
4. 序数词用汉字（第一、第二）
5. 概数用汉字（三四个月、百八十人）
6. 确数用阿拉伯数字（15个单位、300万元）

## 机关名称使用

1. 首次出现用全称，其后可用规范化简称
2. 简称需在首次出现时注明（以下简称"XX"）
3. 不使用非正式简称或口语化简称
4. 多个机关并列按级别先后排列
